# vprodc83.github.io

Site do **Game Catalog**: página de download do aplicativo Android, política de privacidade e termos de uso.

- O conteúdo vem da pasta [`docs/site`](https://github.com/VPRODC83/gamecatalog-app/tree/main/docs/site) do repositório
  [VPRODC83/gamecatalog-app](https://github.com/VPRODC83/gamecatalog-app). Para mudar uma página, edite lá.
- O workflow **Publicar o site** copia essas páginas (e a pasta `extra/` daqui) para o GitHub Pages uma vez por dia,
  a cada push neste repositório e quando rodado à mão em **Actions → Publicar o site → Run workflow**.

A versão web do app (no navegador) foi descontinuada em 03/11/2026.
